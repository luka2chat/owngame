# 箭径出逃

找出移除顺序，让所有箭头离开棋盘。

[在线试玩](https://owngame.dev/play?game=arrow-escape) · [授权与来源](THIRD_PARTY_NOTICES.md)

## 本地运行

需要 Node.js 22.18 或更新版本与 npm。在本目录执行：

```sh
npm ci
npm start
```

打开 http://127.0.0.1:5173 。也可分别运行 `npm run build` 和 `npm run serve`。构建输出位于 `dist/`；运行时素材在本地，不需要游戏运行时 CDN。

## 操作

点击前方没有阻挡的箭头，让它沿尖端方向离开；先移开挡路的箭，清空棋盘即可过关。每关有三次容错，提示与撤销可自由使用。支持拖动、双指缩放、36 关渐进解谜和本地续玩。键盘方向键选箭，回车移出，H 提示，U 撤销，空格回中。
