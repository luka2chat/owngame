# In-game scene snapshots

These WebP files are captures of the published, immutable game builds, using each game's own renderer and assets. `scripts/web/blueprint-scenes.json` records their SHA-256 hashes, game versions, source revisions, capture dates, view labels and corresponding level-card fingerprints.

Tidal Reclaim's inspection views render the actual running scene with a cloned camera. Faune's chapter views and maps come from its normal game and map UI, with chapter selection restored in an isolated capture profile. Other captures show each game's running opening scene. The images demonstrate scene appearance, not campaign completion or new gameplay/device acceptance.

Screenshots retain the original games' and third-party assets' licensing terms. See each linked game's LICENSE and THIRD_PARTY_NOTICES files; CivClicker retains its GPL source and original asset terms. No separate license grant for the captured artwork is implied. No promotional cover or newly invented environment is used as a level snapshot.
