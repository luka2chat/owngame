# 潮光归位：保留风格，修复可变容量

用户已认可琉璃灯塔方向，本轮要求修复灯增加到四个以上时的显示。原图片画死两层槽位，继续叠灯会覆盖塔顶。处理方式是将塔身分为顶部、可重复槽位和底部，灯、提示圈、动画共用位置计算，保留完整塔身的命中区。

内容扩展、容量修复和后续 Web 迁移发生于不同迭代。六层、八层检查用的是测试局面，不能写成新增的正式关卡。可解与完成输入检查，也不代表难度节奏获得了用户认可。

可复用：先确认保留项；用极端状态审查美术结构；只修目标问题；保留规则与旧档。现成图片不一定能适应所有玩法状态。

不应泛化：局部容量修复不需要重新选择整体视觉风格，也不要求迁移引擎。
