# 月下连星 · Web 起点

原创的双人同屏井字棋：星与月轮流落子，横竖斜三连获胜。支持悔棋、重开、本地续玩与键盘操作。无运行依赖、CDN、生成式美术服务或跟踪请求；画面由 Canvas 和 CSS 绘制。

需要 Node.js >=22。无需 npm install：

```sh
npm test
npm run build
npm run preview
```

打开 http://127.0.0.1:3215 。浏览器实际点击完成一局；规则检查不代替视觉和输入检查。关闭服务用 Ctrl+C。

先修改 `src/theme.js` 中的标题与配色，然后重新构建、刷新，确认已有落子仍在。`src/rules.js` 只管规则，`src/main.js` 管交互与存档，`style.css` 管布局。每个由工具创建的项目有独立 `src/project.js` 标识；更新游戏时保持它不变。此示例不含电脑对手。

`dist` 是可静态托管的构建产物，脚本只覆盖带 `.owngame-build` 标识的旧构建。`build.json` 记录源码指纹；不表示试玩通过。长屏、小屏、键盘、撤销、胜负、刷新续玩需要实际验证。离线冷启动、手机 App 和用户对美术的认可都需要另外验证。

损坏或未知版本的存档保持原样并提示暂不保存，不静默覆盖。存储受限时仍可玩，但会显示进度无法保存。首次运行需要 HTTP 服务；不承诺直接双击 file:// 运行。
